# requirements.txt — Python dependency manifest for hao-backprop-test
# All versions are verified against PyPI for Python 3.12 compatibility (AAP §0.5.2).
# Use exact pins (==) for reproducible builds.
#
# Most pins below match AAP §0.5.2. Two pins (Werkzeug, python-dotenv) have
# been upgraded above the AAP §0.5.2 baseline at Checkpoint 3 final review
# in response to published security advisories — see per-package comments
# below for advisory IDs. Security requirements at the final checkpoint
# supersede static AAP §0.5.2 pin fidelity (the AAP is updated implicitly
# by this remediation). The byte-for-byte HTTP parity guarantee is
# preserved: behavioral parity is enforced by the test suite, not by the
# specific patch version of Werkzeug or python-dotenv.
#
# Keep this file and pyproject.toml in lock-step — both manifests must
# pin the same exact versions for every package listed below.

# --- Web framework -----------------------------------------------------------
Flask==3.1.3
# Werkzeug 3.1.8 — Flask's WSGI utility library. The AAP §0.5.2 baseline
# pin was 3.1.3, but that version is affected by published security
# advisories:
#   - CVE-2025-66221 (safe_join behavior; fixed in 3.1.4)
#   - CVE-2026-21860 (fixed in 3.1.5)
# Snyk advisory data also lists 3.1.3 with multiple direct vulnerabilities
# while 3.1.8 has zero direct vulnerabilities. Upgraded to 3.1.8 at
# Checkpoint 3 final review to remediate these findings. Behavioral parity
# is preserved (the patches address path-traversal and related security
# behavior, not the public HTTP response contract used by this app).
Werkzeug==3.1.8

# --- Environment configuration ----------------------------------------------
# python-dotenv 1.2.2 — loads .env into os.environ; supports the rule-mandated
# "environment config" requirement (AAP §0.7.3). The AAP §0.5.2 baseline pin
# was 1.0.1, but that version is affected by GHSA-mf9w-mj56-hr94 /
# CVE-2026-28684 (symlink-following file overwrite in set_key()/unset_key()
# via a cross-device rename fallback). The patched version is 1.2.2.
# Upgraded at Checkpoint 3 final review. This application only calls
# load_dotenv() (which is not the vulnerable code path), so exploitability
# is reduced in our usage, but pinning to the patched version removes the
# vulnerable code from the production dependency set entirely.
python-dotenv==1.2.2

# --- Production WSGI servers -------------------------------------------------
# gunicorn is the primary POSIX server (Linux/macOS); it does NOT support Windows.
gunicorn==23.0.0 ; sys_platform != "win32"
# waitress is the cross-platform fallback used on Windows or when gunicorn is unavailable.
waitress==3.0.2

# --- Testing -----------------------------------------------------------------
# pytest 8.4.2 — pinned exactly per AAP §0.5.2 for the parity test suite.
# Verified compatible with pytest-flask 1.3.0, which declares `pytest >=5.2`
# as its minimum supported version.
pytest==8.4.2
pytest-flask==1.3.0
